2. Warum brauchen wir ein Modell?

Eine Tabelle kann Informationen gut darstellen. Doch jetzt besitzt eine Person mehrere Kartenexemplare, während ein Kartentyp mehrfach vorkommen kann. Wir wollen Eigenschaften und Beziehungen übersichtlich beschreiben.

Leitfrage: Wie können wir sowohl Eigenschaften als auch Beziehungen zwischen verschiedenen Objekten übersichtlich modellieren?

Entitätstyp
Eine Gruppe gleichartiger Objekte, z. B. PERSON.

Attribut
Eine Eigenschaft, z. B. Zustand.

Schlüsselattribut
Identifiziert eindeutig; in Chen-Notation unterstrichen.

Beziehung
Verknüpft Entitätstypen; die Raute benennt sie.

Die Regel lautet: Eine Person kann mehrere Exemplare besitzen; jedes Exemplar hat genau eine aktuelle Person. Das ist eine 1:n-Beziehung. Bei 1:1 gehört auf jeder Seite höchstens eins zusammen; bei n:m können auf beiden Seiten mehrere zusammenhängen.
